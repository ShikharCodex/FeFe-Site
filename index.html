What is FeFe‑Script?

A tiny, hand‑crafted scripting language where you sniff conditions, zoom through loops, and bork your messages. It’s a fully working tree‑walk interpreter written in JavaScript. Perfect for learning language design – or just for pure, unadulterated fun.

Features

😂

Crazy Syntax

Rewrite your brain – sniff / woof for if/else, zoom for while, boop for functions.

🧠

Real Interpreter

Lexer, parser, evaluator – all in clean, modular JavaScript. A perfect learning resource.

⚡

Straightforward

No classes, no modules, no async. Just a single file with everything you need to run your .fe scripts.

🦒

Simple and Easy

Designed for beginners. Minimal syntax. Focus on learning concepts, not wrestling with complex features.

🪸

Zero Dependencies

No external packages. Works everywhere Node.js runs. Install globally in seconds.

🎨

VS Code Extension

Syntax highlighting for *.fe files – because your code deserves to look as good as it sounds.

Ready to Bork?

Install FeFe‑Script globally on your machine and start writing .fe files in seconds. No dependencies, no complex setup.

1

Make sure Node.js is installed

FeFe‑Script runs on Node.js. Grab it from nodejs.org (v18 or higher).

2

Install FeFe‑Script globally

Open your terminal and run the command below. That’s it — you’re now a FeFe developer.

npm install -g fefe-script
3

Create your first .fe file

Write some FeFe code, save it as hello.fe, and run it with fefe hello.fe.

Read the Docs →
hello.fe
// Your first FeFe‑Script program
fe name = "FeFe World";
bork "Hello, " + name + "!";

// Conditionals with sniff / woof
sniff (name != "") {
  bork "Welcome!";
} woof {
  bork "Who's there?";
}
// Output: Hello, FeFe World!
// Welcome!
